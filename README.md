# E.B.YO.F MONEY : versions

Ce dépôt ne contient que les fichiers d'installation (APK) de l'application
E.B.YO.F MONEY, jamais son code. L'application regarde ici la dernière
version publiée et propose de l'installer.

- **arm64-v8a** : presque tous les téléphones.
- **armeabi-v7a** : téléphones anciens.

Les APK sont signés par E.B.YO.F : Android refuse toute copie modifiée.
